# iPhone 鏡頭 → Mac 模型車計數 → ESP32 → Uno

手機只提供畫面。Mac 執行影像分析，經 Wi-Fi 將 A／B 車量傳到現有 ESP32；兩塊板的 `.cpp` 不用改或重新上傳。

## 先接 iPhone 攝影機

使用 Apple「接續互通相機」（Continuity Camera）：iPhone 與 Mac 登入同一 Apple 帳號、啟用雙重認證，並符合 Apple 的裝置／系統要求。iPhone 開啟「設定 → 一般 → AirPlay 與接續互通 → 接續互通相機」（名稱會隨 iOS 版本略有不同）。

建議用 USB 接 iPhone 至 Mac，按「信任」電腦，保持 Wi-Fi／藍牙開啟，並關閉個人熱點。依 Apple 指引鎖定及固定 iPhone，讓後鏡頭朝向模型。可先在 QuickTime Player 的「新增影片錄製」相機選單確認看得到 iPhone，確認後關閉 QuickTime 的相機預覽，避免占用相機。不需要實際錄影。

先關閉人物置中、肖像模糊及背景特效，讓構圖保持不動。Mac 若要求相機權限，允許啟動程式所用的 Terminal／Python；可在「系統設定 → 隱私權與安全性 → 相機」檢查。

官方設定與相容性：[Apple 接續互通相機說明](https://support.apple.com/en-us/102546)。USB 只是相機連線；Mac 仍要連上 ESP32 的 Wi-Fi 才能傳車量。

## 啟動

1. 第一次安裝依賴時先讓 Mac 連上有互聯網的網絡。在此資料夾執行：

   ```sh
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   ```

2. 之後 Mac Wi-Fi 連 **TrafficLight-Lab**，密碼 **traffic123**。兩塊板維持 USB 供電及原來 GPIO17 → D10、GND → GND 接線。關閉之前持續手動傳車量的網頁，避免覆蓋鏡頭結果。
3. 雙擊 `Start.command`。輸入相機編號，先試 `0`。若出現 Mac 內建相機而非 iPhone，按 Q 關閉，重開再試 `1` 或 `2`；每台 Mac 編號不同。
4. 如果找不到 iPhone：先在 QuickTime 確認可用、關閉其他使用相機的 App，再重開本程式。程式使用 OpenCV 的 macOS 相機介面；不同 macOS／OpenCV 版本對接續互通相機的枚舉可能不同。若 QuickTime 可用而本程式不能開啟，請提供錯誤訊息，需進一步調整相機介面。

也可執行 `.venv/bin/python camera_control.py --camera 1`。程式不儲存影片、不上傳影像，只將車量傳給 ESP32。

## 操作順序

1. 手機固定在上方，讓兩條路的等候區都在畫面內。背景最好單色、與車身有明顯色差。
2. 點選影像視窗，按 **R**。拖曳 A 道等候區，按 Enter；再框 B 道，按 Enter。兩區不能重疊，不要包含十字中心、紅綠燈或離場車道。
3. **拿走所有車和手**，等待自動曝光穩定，再按 **B**，記錄空路面。背景只存在記憶體，重開程式需重新設定。
4. 放入模型車，每輛留足空隙（畫面上建議至少 10 像素）。移開手，查看 A／B 計數和綠色偵測框。
5. 計數正確後按 **S**，啟用傳送。連續三次相同結果才會傳送，每秒最多一次。畫面顯示 ESP32 接收成功，不代表 Uno 硬體已回報。
6. 按 **P** 停止傳送並要求固定時間；按 **Q** 離開。

滑桿：`Difference threshold` 調高可減少小亮度變化誤判；`Minimum car area` 調高可忽略小雜點，太高會漏掉小車。調整後等計數穩定。移動手機或更改構圖、燈光後，重新清空道路並按 B。

## 這個版本的辨識限制

這是「空背景差異＋物件計數」，**不是訓練過的汽車 AI 模型**：留在路上的靜止模型車可被計算，但手、其他物品或明顯陰影也可能算成車；相鄰／重疊的車可能被合併，同色車或反光可能漏算／多算。請先在受控模型環境核對計數，再按 S。

大片畫面改變、過大的物件或沒有新影像時會停止傳送有效計數。Uno 自最後一次收到車量起 5 秒後，下一次綠燈使用固定 10 秒；已開始的階段會正常完成。若相機驅動持續重送凍結畫面，單靠讀取成功無法可靠辨認，請觀察預覽並按 P 停止。

## 實體驗收

- 空路面應為 A=0、B=0。
- A 放 3 輛、B 放 1 輛，應顯示 3／1；傳送後下一次 A 綠燈應為 **14 秒**，B 為 **10 秒**。
- 車不動也應保持數量。逐一移走車，確認計數減少。
- 按 P 後，下一次綠燈回復 10 秒。
- 拔掉相機或退出程式，確認不再傳送舊計數，Uno 回復固定時間。

## 已驗證與待驗證

用合成影像測試空背景、分開靜止物件、分區、雜點、大片場景改變及穩定判定；用本機模擬服務測試 ESP32 請求格式。這不代表已在你的 iPhone／模型車完成實測。

```sh
.venv/bin/python -m unittest discover -s tests -v
```

影像處理依據：[OpenCV connectedComponentsWithStats](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html)。
